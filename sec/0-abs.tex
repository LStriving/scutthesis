\begin{abstractCN}
% 硕士学位论文的中文摘要一般约500～800字。摘要内容应涉及本项科研工作的目的和意义、研究思想和方法、研究成果和结论
近年来，深度学习在通用领域的视频动作理解与分析任务中取得了显著进展。
然而，将相关技术迁移至医疗健康场景时，仍存在明显的领域鸿沟。
在临床应用中，相较于自然视频，医疗视频常面临影像对比度低、动作幅度微小、数据分布高度失衡等问题。
上述因素使深度模型难以学习稳定且有效的视觉表征，进而影响动作分析精度。
因此，如何深度融合医学领域先验知识，实现更高效的医疗视频动作理解，对推动智慧医疗系统的实际落地具有重要意义。
本文以辅助诊断的吞咽造影视频和面向术中导航的青光眼手术视频两种典型医疗视频数据为研究对象，
深入探讨了视频动作理解在复杂临床场景下的挑战，具体表现为：
（1）在吞咽造影视频微动作定位任务中，X 射线影像的低对比度及关键结构的模糊与遮挡，
导致微弱动作信号极易被静态背景噪声淹没，致使模型难以精准捕捉动作时序边界；
（2）在眼科手术视频在线识别任务中，手术阶段时长分布失衡以及不同操作间极高的外观相似性，
导致模型在实时推理时极易出现漏检与误判。
针对上述挑战，本文研究内容如下：

对于吞咽造影视频分析，本文针对时序微动作定位中解剖结构模糊、弱目标特征易被淹没的问题，
% 对解剖结构校准机制进行探索。
提出了 \fullname（\sexyname）框架。该框架通过引入基于临床先验的骨架热图模态，为模型提供鲁棒的几何结构参照，
引导模型学习抗干扰能力更强的视觉表征。
此外，为实现多模态特征的高效校准与增强，本方法设计了跨模态特征校准模块 \crossblockshort 和通道级增强机制 \channelblockshort，
该机制以骨架特征引导空间聚焦，显式剥离冗余的静态背景信号，进而有效放大细微的动作特征。
在吞咽造影基准数据集上的实验表明，所提方法相较现有方法平均精度均值提升了 5.3\%，并在外部验证集中表现出良好的泛化能力。
% 这里只谈了显微手术，但是没有聚焦青光眼
对于青光眼手术导航，本文针对在线动作识别中时序逻辑混淆与数据分布不均衡的问题，
% 对手术规程逻辑协同机制进行探索，
提出了 \fulltwo（\sexytwo）在线动作检测框架。该方法利用手术流程的结构化先验，
通过动态逻辑演化模块 \graphmoduleshort，提升模型对状态转移与动作持续时长的感知能力，
从而学习逻辑一致性更强的场景表征。此外，本文还提出类别边界加权损失 \lossshort，以实现长短时动作特征的均衡学习。
在自建的微创青光眼手术数据集及公开数据集 OphNet 上的实验表明，
相较于现有方法，本文所提出的方法分别取得了 0.9\% 和 1.9\% 的在线识别准确率提升。
